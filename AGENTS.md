# AGENTS.md

## Purpose

This repository is for connecting compatible AI clients to the official OpenSEO MCP server.

## OpenSEO MCP

Use this server:

```text
https://app.openseo.so/mcp
```

Before doing SEO work:
1. Confirm OpenSEO MCP is connected and authorized.
2. List/select the relevant OpenSEO project when project context is required.
3. Prefer current OpenSEO data for keyword metrics, SERPs, competitors, backlinks, rank tracking, and GSC data.
4. Keep factual metrics separate from SEO recommendations.
5. Never expose or commit API keys or OAuth tokens.
